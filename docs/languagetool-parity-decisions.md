# LanguageTool parity: decisions for the maintainer

The LanguageTool parity work ([evaluation](languagetool-parity-evaluation.md)) skipped some LanguageTool (LT) rule families and did only part of others. This page lists them so the maintainer can decide what happens to each one.

## How to use this list

- Each row is one LT rule group (its `rulegroup` id, or the rule id when there is no group), or a family of small groups that share one reason.
- **Missed** is `missed / incorrect`: of LT's incorrect examples for that group, how many get no overlapping Review finding. Counts come from the full harness run on `lt-parity` at `7422722a`, the run in the evaluation's Snapshot. Rerun the harness before acting on a row.
- **Reason** uses one of these labels:
  - _LT list_: needs LT's word, phrase or name list, which we may not copy.
  - _clock_: the result depends on the day the check runs.
  - _LT contradicts_: LT has rules both ways, its example is wrong, or the usage is accepted.
  - _precision_: a general rule would flag correct prose.
  - _data/size_: needs lexicon data we lack, or data that would grow the bundle. `background.js` already grew from 1.7 MB to 4.5 MB.
  - _regional_: written for a variant FluentTyper has no locale for (en-GB, pt-PT, de-CH, de-AT).
  - _style_: register or opinion, not an error.
- **Suggested option** is a starting point. "Theme Tn" means the row follows the cross-language decision of that theme.
- **Fill in the Decision column.** Use, for example: `implement`, `opt-in`, `skip`, `later`, or a norm choice. A row marked `implement` or `opt-in` becomes a work package. The usual rules still apply: our own tables and sentences, never LT's, and precision first.
- Partly done groups are listed only when the misses that remain need a decision. Ordinary leftovers of a working rule are not listed. Greek has no misses and is not listed.
