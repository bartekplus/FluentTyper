# Find your typing rhythm

[FluentTyper](../README.md) / Typing and shortcuts

Choose how suggestions appear. Save short names for the phrases you use most.

## Popup or inline?

**Popup mode** shows a list of words. **Inline mode** shows one suggested ending beside your cursor.
The [README shows both modes](../README.md#choose-from-a-list).

These instructions use the default Tab shortcut. Settings can change how you accept suggestions.
Press **Esc** to dismiss a suggestion.

## Change your mode

1. Open the FluentTyper extension popup.
2. Select **Settings**.
3. Open **Essentials**.
4. Turn **Enable inline suggestion** on for inline mode, or off for popup mode.

A [site profile](site-settings.md) can override this choice on a particular website.

## Reuse a phrase

1. Open **Settings** from the extension popup.
2. Select **Snippets & Dictionary**.
3. Select **New snippet**.
4. Enter the shortcut and the phrase it should insert.
5. Select **Save snippet**.
6. Type the shortcut in a supported text field.
7. Accept its expansion from the suggestions.

For example, you can set `callMe` to expand to “Call me back once you're free”.
Choose shortcuts that you are unlikely to type as ordinary words.

## Choose a writing language

Open **Settings → Languages** to choose your enabled writing languages and language preference.
For one website, use its [site profile](site-settings.md).
See [language coverage](review-language-matrix.md) for the available spelling and Review checks.

## If suggestions do not appear

- Check that the extension is enabled and allowed on the current site.
- Check that your browser grants FluentTyper access to the site.
- Type more letters. The minimum word length is a setting.
- Check the site's profile if its behavior differs from other websites.
- A website's own autocomplete can take priority. Check **Prefer native autocomplete** if you want to change that behavior.

Password fields and some other fields do not allow typing assistance. Browser-owned pages can also restrict extensions.
Google Docs has its own [instructions and browser limits](google-docs-integration.md).

If the issue continues, [report the browser, extension version, and steps](https://github.com/bartekplus/FluentTyper/issues/new?template=bug_report.yml).
Use example text instead of private content.
