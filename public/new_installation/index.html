Quick Start Guide 🚀

1
Reload your tabs for the extension to activate on already open pages.
2
Start typing in any text field, and watch the suggestion menu magically appear.
3
Use Arrow Keys (↑, ↓) to navigate suggestions and Tab to accept them.

Pro tip: Press Escape to quickly hide suggestions anytime.
